# COVID-19 Exploratory Data Analysis

## What is this?
I analyzed the COVID-19 dataset as part of my data analytics internship at CodeAlpha.
The goal was to explore the data and find patterns and trends from the pandemic.

## Dataset
Our World in Data - COVID-19 Dataset (downloaded as owid-covid-data.csv)

## Tools I Used
- Python
- Pandas (for data cleaning and analysis)
- Matplotlib (for charts)

## What I did
- Cleaned the data and fixed date formats
- Looked at how cases and deaths grew over time
- Found the top 10 countries by cases and deaths
- Compared which continents were hit the hardest
- Used 7-day rolling average to smooth out daily spikes
- Plotted cases vs deaths to see the relationship

## What I found
- USA had the most cases and deaths in 2020
- Europe and North America were the hardest hit continents
- Cases grew slowly at first then exploded after March 2020
- Daily new cases were very jumpy so rolling average helped see the real trend
